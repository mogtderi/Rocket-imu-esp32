# Rocket IMU: ESP32 + GY-801

تخمین زاویه (Roll / Pitch / Yaw) برای راکت آزمایشی با ESP32 و ماژول GY-801، به‌همراه نمایش سه‌بعدی زنده روی کامپیوتر.

## قطعات
- برد ESP32
- ماژول GY-801 (شامل ADXL345، L3G4200D، HMC5883L، BMP180)
- بردبورد و ۴ سیم جامپر

## سیم‌کشی
| GY-801 | ESP32 |
|---|---|
| VCC_IN | 3.3V |
| GND | GND |
| SDA | GPIO21 |
| SCL | GPIO22 |

اگر با ۳.۳V سنسورها پیدا نشدند، VCC_IN را به پین 5V/VIN ببرید.

## راه‌اندازی
1. سیم‌کشی را انجام دهید.
2. کد `firmware/i2c_scanner` را آپلود کنید و مطمئن شوید آدرس‌های `0x1E`، `0x53`، `0x69` و `0x77` دیده می‌شوند.
3. کد `firmware/rocket_imu` را آپلود کنید (حدود ۳ ثانیه راکت را ثابت نگه دارید تا ژیروسکوپ کالیبره شود).
4. روی کامپیوتر:
   ```bash
   pip install -r tools/requirements.txt
   python tools/visualizer.py COM3
   ```

> ✅ روی سخت‌افزار واقعی (ESP32 + GY-801) تست شده است. یک ویدیوی کوتاه از آن در پوشه‌ی docs هست.
